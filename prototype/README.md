# Local prototype

The first prototype will run locally and use deterministic, inspectable processing.

## Milestone P0

Input: a small folder of video clips.

Output:
- `analysis.json` with measurable clip metadata
- `timeline.json` with selected segments
- rendered MP4 generated by FFmpeg

No paid API is part of P0.

## Verification

Every milestone must be executed against real sample footage before being described as working.
